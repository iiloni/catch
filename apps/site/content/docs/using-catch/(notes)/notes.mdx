## Create a note

1. Select **+** to open **New note** above the dock.
2. Write your text. Use the toolbar to format it and **Background color** to choose a color or tag, including a child tag.
3. Select **Save to Gallery** or **Save to Deck**, depending on the destination shown. **Expand** opens the full editor if you need more room.

The quick note also has **Save link** for [capturing a web page](/docs/using-catch/links-and-sharing). You can add files with **Attach files**.

Catch does not have a separate title field. The first line of text stands in for the note's title in places that need one. Use a heading if you want a title to stand out.

## Edit and format

Tap or click a note to open it. Edit directly in the note; Catch saves as you work. **Close**, the back gesture or Escape closes the editor. An empty new note is discarded when you close it.

On a wide screen, a note opened from Gallery, Reminders, Archive or Trash sits in a pane beside the page. **Expand note**, next to **Close**, gives the note the whole window; **Show gallery** brings the page back. This device remembers the choice for the next note you open.

While typing on a phone, the dock becomes a formatting toolbar. Scroll the toolbar horizontally to reach more controls. It offers **Bold**, **Italic**, **Underline**, **Strikethrough**, **Heading**, **Bulleted list**, **Numbered list**, **Checklist**, **Indent** and **Outdent**. Check a checklist box to mark an item complete. To clear finished items, open a checklist item's menu from its drag handle and choose **Delete all checked items in note**.

<DocsScreenshot name="androidKeyboard" caption="The formatting toolbar sits above the Android keyboard while you edit a note." />

Use **Slash menu**, or type `/`, to choose a block. The editor supports paragraphs, headings, lists, checklists, tables, code blocks and media blocks. Blocks can be moved with their drag handles. Use **Undo and redo** to open the editor's **Undo** and **Redo** controls. To review saved content after leaving the editor, open [Version history](/docs/using-catch/version-history) from the note's footer beside its edited time.

Open notes have **Pin**, **Archive** and **Move to trash** in the header. The dock offers **Background color**, **Tags**, **Attach files**, **Move note** and **Reminder**. If the keyboard is showing formatting controls, dismiss it to reach the other dock actions.

## Code blocks

Code blocks highlight their code's syntax. Hover over or tap the language label at the top of a block to show its tools:

- The language label opens **Code language**. Search the list or choose **Detect language** to let Catch work it out.
- **Copy snippet** copies the code, and **Download snippet** saves it as a file named for its language.

When you paste code into an empty code block, or paste text that becomes a code block without naming its language, Catch detects the language for you. If it cannot tell, choose one from the list.

## Shorten a note's card

To keep a long note's card short, choose **Preview cutoff** from the slash menu. The note's card ends at that line, and the full note still shows everything. Choosing it again moves the line, and the **X** at the end of the line removes it. If a note ends up with more than one, for example by pasting, the first one counts. A cutoff with nothing above it is ignored, so the card shows the note as usual.

## Read the save status

- **Syncing…**: changes are being saved or are waiting to sync.
- **Synced**: pending changes have finished syncing.
- **Saved on this device**: changes are kept locally while the server cannot accept them.
- **Not saved**: a save failed. Read the error message and address it before leaving the note.

Local changes need to sync before another device can see them. Read [Offline and updates](/docs/using-catch/offline-and-updates) for connection problems and conflicts between devices.

## Make a copy

[Select the note](/docs/using-catch/organizing#select-several-notes), then choose **Make a copy**. Copies keep the note's content, tags and attachments; their attachment files are independent. A reminder is not copied.
