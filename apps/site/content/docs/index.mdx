Catch stores your notes on a server you or someone you trust runs. You use it in a browser, as an installed web app, or through the Android app. This public documentation site is separate from your Catch server: you do not sign in or keep notes here.

<Cards>
  <Card title="Using Catch" href="/docs/using-catch">
    Get the app, sign in, write notes and keep them organized across devices.
  </Card>
  <Card title="Running a server" href="/docs/running-a-server">
    Install Catch with Docker, invite people, configure HTTPS, back up and update.
  </Card>
</Cards>

If you are moving from Google Keep, start with [Import from Google Keep](/docs/using-catch/google-keep). If changes are waiting on your device, read [Offline use and updates](/docs/using-catch/offline-and-updates).

These guides describe the features implemented on the repository's `main` branch. Your installed release may be older; check **Settings > Update** and the [changelog](/changelog) when a control described here is missing.

To work on Catch itself, use the repository's [development guide](https://github.com/iiloni/catch/blob/main/DEVELOPMENT.md) and [architecture decisions](https://github.com/iiloni/catch/tree/main/docs/decisions).
